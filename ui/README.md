# Living World AI interface

This is the production React presentation layer for the local Node game server.

On Windows, double-click the **Living World Studio** desktop shortcut or `start.bat` at the repository root. Install the shortcut with `scripts/install-desktop-launcher.ps1` after moving the checkout. The launcher starts Docker Desktop when needed, starts/reuses the preview backend and Next development renderer, and opens `http://127.0.0.1:3105/admin`. Repeated launches reuse the running services; concurrent launches wait for startup. Source edits reload automatically. The game entry stays on port 3100 and redirects to the protected realm when enrolled. Keep the minimized launcher window open; Ctrl+C stops only its own child services. It does not activate Codex, change account settings or install dependencies. Development output uses `.next-dev`, separate from release builds.

`/admin` is one AI Studio: a persistent developer conversation and its evidence, an inspectable World Lab, and provider configuration sit in the same surface. The chat uses the official AI Elements registry sources directly: `conversation`, `message`, `prompt-input`, `reasoning`, and `shimmer`. Its evidence and developer views use the official AI Code Elements sources: `agent`, `task`, `checkpoint`, and `model-selector`, alongside the project’s shadcn primitives.

The registry source is kept in `ui/components/ai-elements` so the autonomous developer can inspect and improve the same components it uses. Build it with `npm run ui:build`; `npm start`, the test suite, and both browser labs do that first.

The authenticated preview remains on port 3100 with its separate database.

This is still a trusted current-source preview, not a general saved-candidate execution or promotion lane.

Live execution narration is always visible above the composer. Use the unchanged AI Elements Tool compound components for actual CLI tool receipts; never relabel fixed phase copy as model reasoning, fabricate calls, or imply that a quiet open process is making progress. Preserve explicit legacy telemetry gaps and distinguish a failed tool from a failed development attempt.

The Evidence tab exposes real developer attempts and retained planning proposals with Plan, Checkpoint, Task, CodeBlock, Tool/ToolOutput and actual test logs through Terminal when present. The existing Conversation, PromptInput, Message, Shimmer, ModelSelector and WebPreview remain wired to their real capabilities. Stopped scheduling is a blocker, not Ready.

The composer contains the saved model/effort settings, Send and active-run Stop. With a draft during a run, Send queues a follow-up and Stop stays available. Stop also pauses automatic scheduling. Resume starts a fresh attempt with retained candidate data where available, fresh validation and unchanged model/budget limits; it never replays an interrupted paid turn. Public agent messages appear in the conversation between collapsed tool groups; private reasoning is excluded. Existing runs without public-message telemetry cannot acquire historical narration retroactively.

Ask now queues a read-only question through the connected, enabled account using its saved route and limits. It reads an isolated project copy and returns the agent's public answer. Source changes reject the answer attempt; this branch cannot enter implementation or release. Plan remains stored context and Agent remains the implementation path. When execution is unavailable, questions are retained with the blocker rather than pretending an agent answered.

The remaining admin views now use shared shadcn sections, tables, dialogs and empty states. Connections starts with Codex and separates inactive world providers from development accounts. The searchable AI Elements ModelSelector uses the connected account's catalog names; model and effort selectors also work in the composer, with the actual run route displayed separately from the saved automatic preference. Only supported host effort values are offered. No presentation refresh submits settings.

Evidence provides searchable/filterable attempts and an immediate inspector with candidate claims, independent staging reasons, checks, changed files and final release receipts.
